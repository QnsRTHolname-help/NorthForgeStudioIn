# NorthForge OS Ecosystem Strategy

NorthForge should become the daily operating layer for service businesses: the place owners open in the morning to understand the day, keep open during work to manage leads/projects/people, and check at night to see what changed.

The first focused niche is interior design businesses. They usually have high-ticket projects, long sales cycles, many moving parts, client approvals, site visits, vendors, employees, files, payments, and follow-ups. That makes them a strong starting niche for a unified operating system.

## Core Positioning

NorthForge is not only a website, automation setup, or CRM. It is the system that keeps the business connected:

- Leads come in from website, WhatsApp, forms, email, and referrals.
- The owner sees what needs attention today.
- Employees update project work without cluttering the owner's view.
- Clients receive timely updates, reminders, and onboarding messages.
- Automations run quietly in the background.
- The business knowledge base grows over time.

The goal is to make leaving NorthForge feel like losing visibility into the business. That should come from genuine usefulness, not tricks: fewer missed leads, fewer forgotten tasks, clearer employee accountability, faster client communication, and better daily decisions.

## Product Principles

1. Start the day inside NorthForge.
   The dashboard should answer: What happened while I was away? What is urgent today? Which leads, clients, projects, employees, and payments need attention?

2. Make every important action one step closer.
   Messaging, appointments, project updates, lead follow-ups, files, tasks, and employee activity should be reachable without bouncing between many apps.

3. Separate owner clarity from employee activity.
   The owner needs a clean command view. Employees need focused workspaces. NorthForge should connect both without mixing everything into one noisy dashboard.

4. Customize by business type.
   Interior designers, architects, startups, agencies, clinics, consultants, and other niches should not see the same generic dashboard. Each dashboard should match the work model of that business.

5. Create healthy daily engagement.
   Use feedback, progress, quick wins, summaries, and clear status signals to make the product satisfying. Avoid dark patterns, fake urgency, or empty engagement loops.

## Interior Design Dashboard

The interior design dashboard should be the first premium niche dashboard.

### Owner Home

- Today's appointments, site visits, calls, and client meetings
- New enquiries and leads requiring reply
- Active projects with stage, deadline, and owner
- Client approval requests waiting
- Pending payments and invoices
- Employee updates since last login
- WhatsApp/email messages needing attention
- Automation health and recent workflow activity

### Leads

- Source: website, WhatsApp, Instagram, referral, email, manual
- Requirement: residential, commercial, renovation, full interior, furniture-only
- Budget range
- Location
- Timeline
- Lead score
- Next action
- Assigned employee
- Follow-up history

### Projects

- Pipeline: Enquiry, Consultation, Design, Quotation, Approval, Execution, Handover, Review
- Project timeline
- Rooms/spaces
- Material selections
- Vendor tasks
- Client approvals
- Files and drawings
- Site photos
- Payment milestones
- Employee contributions

### Calendar

- Client consultations
- Site visits
- Design reviews
- Vendor deadlines
- Payment reminders
- Employee tasks
- Automated WhatsApp/email reminders

### Tasks and Todo

- Owner tasks
- Employee tasks
- Client-facing tasks
- Internal tasks
- Recurring tasks
- Project-linked tasks
- Priority requests for NorthForge support

### Client Communication

- WhatsApp inbox or conversation summaries
- Email summaries where connected
- Automated acknowledgement
- Follow-up sequences
- Appointment confirmations
- Onboarding messages
- Review requests after handover

### Employee Portal

Employees should have a separate portal linked to the client dashboard.

- Client creates employee slots from the Employees tab.
- Client sets up a simple access flow.
- Employee opens the generated portal link.
- Employee creates profile and password.
- Employee sees only assigned projects/tasks.
- Employee can upload updates, files, notes, photos, and task status.
- Owner can see contributions and activity without cluttering their main dashboard.

For security, the final implementation should use individual employee accounts or invite links instead of a shared password-only system. Shared passwords are easy to misuse and hard to audit.

## Plan Strategy

The pricing should make each tier feel valuable while protecting margin. The difference between tiers should be visible in outcomes, not only in longer feature lists.

### LEAD: Rs. 7,500/month + Rs. 15,000 setup

Positioning: For businesses that want every enquiry captured, replied to, and organized.

Include:

- Lead capture from website, WhatsApp, form, or one selected channel
- Automated acknowledgement
- Basic AI FAQ assistant
- Basic lead qualification
- Proper lightweight CRM
- Basic appointment scheduling
- Lead notifications
- Basic follow-up automation
- Basic analytics
- Task and todo tab
- Calendar view
- Owner dashboard
- Up to 2 workflows
- 1 core integration
- 3 included users or employee seats
- Extra employees at Rs. 600/month each
- Company Second Brain as Rs. 2,000/month add-on

Dashboard feel: basic/premium. Clean, focused, and not overloaded.

### CONVERT: Rs. 15,000/month + Rs. 30,000 setup

Positioning: For businesses already receiving steady enquiries and needing stronger conversion control.

Include everything in LEAD, plus:

- Advanced AI customer assistant
- Better lead qualification, scoring, and segmentation
- Full CRM pipeline
- Multi-step WhatsApp and email follow-up sequences
- Appointment reminders
- Conversion analytics
- Up to 5 workflows
- Up to 3 integrations
- 1 AI agent
- Employee portal with 15 included employees
- Extra employees at Rs. 500/month each
- Company Second Brain included
- Monthly optimization

Dashboard feel: apple/premium. More refined, calmer, and more powerful than LEAD.

### AUTOPILOT: Rs. 30,000/month + Rs. 60,000 setup

Positioning: For businesses that want NorthForge to run multiple repetitive operations, not only lead management.

Include everything in CONVERT, plus:

- Custom AI workflows across business processes
- Multiple AI agents where useful
- Advanced WhatsApp automation
- AI voice receptionist where suitable
- Custom onboarding messages across WhatsApp and email
- Workflow request and priority automation tab
- Advanced CRM automation
- Automated reports and owner dashboard
- 10+ workflows, subject to discovery and infrastructure limits
- Employee portal with 30 included employees
- Extra employees at Rs. 500/month each
- Priority support
- Continuous optimization within agreed scope

Dashboard feel: premium executive system. Theme options: cream white, cream peach, and Burberry-inspired cream/brown.

## Psychological Pricing And Retention

Use pricing psychology ethically: make the value obvious, reduce buying hesitation, and reward long-term customers without hiding costs.

### Recommended Structure

- Keep CONVERT as the recommended/default plan.
- Make LEAD feel complete enough to start, not crippled.
- Make AUTOPILOT feel like a serious upgrade for owners who want less operational involvement.
- Show the setup fee separately, because setup is real work and should not look arbitrary.
- Use annual or quarterly commitment benefits later, once delivery capacity is predictable.

### Offers

- First-time setup discount for early beta clients.
- Founder client pricing for the first limited batch in one niche.
- Monthly offer only when attached to a real reason, such as beta onboarding, festival campaign, or limited implementation slots.
- Avoid constant discounts, because they teach clients to wait.

### Retention Model

Retention should come from data, workflow history, employee usage, and business memory.

- Daily owner summary
- Weekly performance report
- Monthly optimization call or async review
- Client-specific knowledge base
- Employee contribution history
- Project and lead history
- Automation logs
- Integrated WhatsApp/email/calendar records

When the client's data and routines live in NorthForge, switching away becomes inconvenient because the business loses context and continuity.

## Ecosystem Integrations

Priority integrations:

- WhatsApp: must-have for India-first businesses
- Gmail or email inbox summaries
- Google Calendar
- Google Sheets
- Website forms
- Slack for foreign or startup clients
- Payments/invoices later
- File storage later

The integration goal is not to replace every app immediately. The first goal is to make NorthForge the control center where the owner sees important signals from those apps and takes action quickly.

## Feedback Loop

NorthForge should actively learn from each client.

- Ask for feedback every 2 weeks during beta and early paid delivery.
- Ask targeted questions, not generic "how is it going?"
- Track requested changes by plan, niche, and urgency.
- Turn repeated requests into product features.
- Use the workflow request tab for AUTOPILOT and later for other plans.
- Keep 24/7 support as a promise only when there is a real support process behind it.

Suggested biweekly feedback questions:

- What did NorthForge save you from doing manually this week?
- What did you still have to manage outside NorthForge?
- Which screen did you open most often?
- Which notification was useful?
- Which notification was annoying?
- What should be one click faster?

Each dashboard should share the same NorthForge core: leads, CRM, calendar, tasks, files, communication, workflows, analytics, support, and settings. The difference should be the labels, project stages, key metrics, default workflows, and daily owner summary.

## Product Roadmap

### Alpha

- Internal NorthForge use first
- Validate lead capture, CRM, tasks, calendar, follow-ups, WhatsApp records, and support
- Build the interior design dashboard as the first niche experience
- Use real empty states, not fake data
- Keep integrations limited but reliable

### Beta

- Onboard a small batch of interior design businesses
- Offer founder pricing or setup discount
- Run biweekly feedback loops
- Improve dashboard layout, employee portal, notifications, and workflows
- Measure which tabs are actually used
- Build repeatable onboarding templates

### Paid V1

- Finalize LEAD, CONVERT, and AUTOPILOT plan boundaries
- Add plan-specific dashboards and theme treatments
- Add second brain offering
- Improve reports and owner summaries
- Add stronger employee permissions
- Add integration marketplace-style UI

### App Version

Build the mobile app only after alpha and beta prove what people open daily.

The app should focus on:

- Morning summary
- Urgent lead replies
- Calendar
- Tasks
- Employee updates
- Client/project notifications
- Support and workflow requests

The website remains the full command center. The app becomes the low-friction daily companion.
